07 · Notificações

Mensagens para o seu celular

Um site sozinho não consegue empurrar notificação pro seu celular sem um servidor por trás. O caminho mais simples sem precisar montar backend: conectar este painel a um bot do Telegram seu — daí qualquer botão daqui pode te mandar mensagem direto no chat.

Conectar bot do Telegram
  1. No Telegram, fale com @BotFather → /newbot → copie o token gerado.
  2. Fale qualquer coisa com o seu bot novo, depois acesse api.telegram.org/bot<TOKEN>/getUpdates no navegador para achar seu chat id.
  3. Cole os dois campos abaixo. Ficam salvos só neste painel.
Bot token
Chat ID
Instalar como app no celular

Para ganhar ícone na tela e abrir sem barra de navegador, hospede os 4 arquivos (index.html, manifest.json, sw.js, icon.svg) juntos — por exemplo GitHub Pages, Netlify ou Vercel, todos gratuitos. Depois:

  1. Abra o link no navegador do celular (Chrome no Android, Safari no iPhone).
  2. Toque em Adicionar à tela de início.
  3. O painel abre como app, com ícone próprio e funcionando offline.
